# Research 012 — 回归真实人物的视觉可信度（CSS-only）

## 为什么重新研究

P1–P8 解决了模块组织、参数和可复现性，但没有证明画面像真人。本轮**不把 CI 通过视为艺术成功**，也不把“增加 CSS 规则”视为造型进步。任务是减少面部拼接感、蜡像感与发盔感，让五官拥有共同的明暗和深度关系。

## 本轮可运行候选

- **冻结对照组**：主页面原始渲染（没有 `r012`），不改动旧 R005–R010 对照。
- **R012 形体候选**：`standalone.html?r012=form`，仅使用 HTML 元素与 CSS 渐变、轮廓、遮罩、阴影；无 SVG / Canvas / 图片贴图。
- CSS 候选以眉弓→眼窝、鼻梁→鼻尖、颧骨→下颌、额头→面颊为连续明暗连接，适度拆除“两个机械对称眼睛+假发盔”的构图感；研究参数不进入人物 JSON v2。
- 通过 `test/research012-preview.py` 的两人物 × 两灯位 × 基线/候选 = **8 张原生 Chromium CSS 截图**；附成组画廊和几何属性。它仅证明同源画面发生变化，不自动判定优劣。
- CI 会在工作流日志输出可解码的低码率真实截图供研究员审查；无须依赖受配额限制的 Actions artifact 存储。

## 艺术判断：明确不能自动通过

五个必须由独立观察者评价的项目，每项 1–5 分：

1. **整体是否像一个活人的头部**：没有蜡像/面具/卡通塑料感。
2. **眼窝与视线**：眼睛嵌入颅面，不像两个贴上去的圆环。
3. **鼻—颧—嘴—颌的体积连续性**：明暗一致，五官不漂浮。
4. **头发生长/边界**：不再像一顶单一黑色头盔。
5. **跨光线身份可信度**：两张同人不同灯位仍像同一人。

至少 5 位独立成年人盲评；对两版随机标记 A/B，每位观察者按两位人物×两灯位的配对图独立给分。由每位观察者汇总每个指标的配对差值，再计算跨观察者的中位数。候选获得 **≥75% 的观察者整体偏好**且关键指标（真实感、眼窝、体积、头发）中位差值均 >0，才可标记为 `PROMISING_NEEDS_REPLICATION`。否则保持 `ART_UNVERIFIED`，不擅自切换生产默认或宣称照片级真实。

## 边界和已知技术债务

- 仍只是 2.5D CSS 绘制，不是正交真实解剖/3D 模型；不能以渐变数量替代艺术审美。
- 真正具备辨识度的不同人种、年龄和皮肤微结构尚未证明；皮肤纹理仍是艺术近似。
- 浏览器自动化、图片像素差异或 AI 评分都不是独立人类盲评。
- 若本方案无美术提升，回退 R012 候选；保留基线/失败记录。
- 下一轮应研究颅面比例与眼球/面部组织的形变约束，而不是继续增加 UI 按钮。

## 首轮真实截图审查（2026-10-15）

从 GitHub Actions 的八帧真实 Chromium 拼图审阅，**R012 候选暂不通过艺术质量验收**，原因不是程序错误，而是画面仍呈现明显人偶/面具特征：

- 两个身份在正面、侧光场景下仍像同一张脸的轻度参数变形，不具备清晰稳定的独立视觉身份。
- 候选版面部下半部过暗，颧骨到下颌形成突兀黑块；体积连续性并没有被证明优于基线。
- 发际线仍是硬边框，横向重复纹理更像条纹塑料帽而不是沿颅骨方向生长的头发。
- 眼窝和睫毛仍有模板化对称感；口鼻缺少细节与可信的皮肤折叠关系。
- 正面/侧面光的视感变化偏弱；仅通过变量和像素差异无法替代艺术评价。

**审查结论：R012_FIRST_VIEW_NOT_ACCEPTED**。保留实验、继续改善解剖结构与头发走向，绝不把本轮的技术通关表述为“真人写实已经完成”，也不将候选切换为默认样式。
