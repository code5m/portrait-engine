# Research 007：共享面部结构坐标是否能减少 CSS 肖像的「面具感」？

## 技术假设与边界

前六轮让 CSS 肖像拥有九个参数、12 个共享光照法线、照片式对照工作流，但面部的眼睛、鼻翼、颧骨、下颌依然存在**互不相关的 CSS 绝对坐标**。更改参数会让阴影和器官分别移动：技术上能重绘，不代表自然。

本轮研究假设是：引入一套**面部局部参考系**，让同一解剖结构的不同 CSS 节点读取相同锚点，有助于结构一致性和可解释性。这个假设首先可以客观验证「位置关联」，但**不能通过自动测试验证真人写实度**。

**不意味着**发明了新语言/可解释三维人脸：R007 的 `FaceGeometry` 是原创二维布局模型，采用经验比例，不代表医学解剖、扫描数据或物理遮挡。之前提出的「Portrait Structure Language (PSL)」仅是长期研究假说，还没有实现。

## 已实现的最小、可回退实验

1. `src/face-model.mjs`：以 `.face` 的 **207×304px 局部坐标**为唯一绘画坐标系；16 个锚点组成眼睛—眼窝—眉弓、鼻根—鼻底—鼻翼、颧骨—下颌—下巴和口部的依赖关系。宽脸依旧使用原来的 `.face` 水平缩放，避免双重缩放。`deriveFaceGeometry()` 为纯计算、无浏览器副作用；`deriveFaceStructureStyle()` 输出共 32 个 CSS 自定义属性。
2. `styles/study007.css`：眼睛、眼窝、眉骨和眉毛共享相互关系；鼻根、鼻翼、鼻侧阴影共享鼻部结构；颧骨、面颊阴影、下颌轮廓、下颌体面共享颊颌锚点。R006 的**同一光照体面计算**继续被两组方案共用，不擅自改变阴影物理假设。
3. `?r007=baseline` 与 `?r007=structured`：都启用 R006 体面阴影，唯一区别是是否使用 FaceGeometry 关联位置。没有研究参数时仍使用原版默认人脸；研究状态不会写进浏览器已保存的 7/9 参数作品，不改变 JSON v1。
4. `study/007-compare.html`：公开 A/B 对比页（不是匿名评审）；`study/007-blind.html`：随机隐藏候选实际名称，按眼部、鼻部、下颌及整体可信度评分，仅本地导出 JSON，不自动上传；**页面路径在开发者工具里可能暴露候选**，属于有限单盲，不冒称双盲。
5. `scripts/build-standalone.py` 将新模块与样式嵌入自包含 `standalone.html`，并移除单文件无法访问的独立对比页链接。现有 CSS 画法、完整历史研究、离线工作台继续保留。

## 测试与可复现证据

```bash
npm run verify
python3 test/browser-qa.py
python3 test/study007-visual.py
```

新增单元/契约测试检查 16 个有限锚点、人脸局部→整体变换、眼间距与眼窝同时移动、鼻翼左右相对鼻底展开、下颌与颧骨联动、7/9 JSON 兼容、CSS 变量被真实图层消费、实验未影响默认存档。

Chromium 真实渲染：2 种方案 × 3 种脸宽（80/100/120%）× 3 种下颌（82/100/118%）× 3 个光向（-60/0/+60°），总共 **54 张**，在 `test-results/research-007/` 生成单帧 PNG、组合图和 `observations.json`。对照 DOM 实测位置：眼睛中心与眼窝中心、鼻根与鼻翼、颧骨阴影及下颌线共同锚定；检查越界、手机横向滚动和 JS 错误。还有匿名评价页导出 JSON 的浏览器功能检查。PNG 是 QA **输出**，不参与产品肖像绘画。

某些隔离容器会屏蔽 localhost 导航，测试脚本如实记录 `inline_fallback=true` 并改用 `set_content()` 内联**同一份** standalone 源码；GitHub CI 应尽可能验证真实 HTTP 页面的渲染。

## 视觉审核与失败记录

从三向光照对比能确认：面部器官与阴影随同一套 2D 锚点联动，窄脸和宽脸极值没有出现新的器官越界。可是**新方案的鼻部亮柱、眼白几何感、头发硬边并未解决**；在某些光线下新眼窝附近显得更暗，可能甚至**降低人物自然度**。不能因为基线与实验有像素差，就说真实性变好了。

**艺术评审状态：`ART_UNVERIFIED`。** 实际独立观察者评分为 0；需要至少三名独立观察者才能分析哪一版更自然。评分应包含原始 JSON、样本数量、每种方案分布，不能仅报告平均分；自动测试中的虚构评分必须丢弃，不得冒充真人反馈。

## 保留与下一步

- **保留 R001–R006 所有研究、测试、源码与 CSS 主线，不修改默认肖像。** 新数据模型仅在隔离 R007 参数下生效。
- 反省复杂度：该模型创建了新的坐标共享关系，却**没有证明**新画法一定更好；只有在真人评分更高或维护成本显著改善后才考虑合并默认绘画。
- 下一项值得探索的是对眼球、鼻梁和嘴唇的**体积连续性**进行定量/主观研究，而不是无限叠加 CSS 阴影。
- 若实验持续失败，可在**显式独立**的候选中尝试 SVG/Canvas，但不能偷换纯 CSS 实验定义，也不能抹除失败记录。
