# Research 005：眼窝与口周形体的可证伪 CSS 绘画实验

记录日期：2026-10-14 · 主仓库：[code5m/portrait-engine](https://github.com/code5m/portrait-engine)

## 研究动机

Research 004 的图像仍然具有“洋娃娃/几何面具感”：正圆瞳孔太突出、眼球与眉骨缺少遮挡，嘴唇像一条横向渐变。单纯增加更多颜色渐变无法证明艺术质量提高。

这轮**不把新方案默认替换旧版**，而将它们隔离成能被否定的 CSS 变体。目标是拿到来自真实观察者的比较意见，而不是自行宣布新版更好。

## 三个比较对象（画面同人、同光源、同尺寸）

| 内部代号 | 原理 | 更改范围 |
| --- | --- | --- |
| `baseline` | Research 004 当前公开版，对照组 | 不加 Research 005 的形体修饰 |
| `orbital` | 加深眼球所在的眼眶与眉弓关系，压低眼白亮度、收窄眼球圆度，形成上眼睑遮挡 | 眼窝、眉骨、眼白、虹膜、眼睑 |
| `expression` | 在 `orbital` 上进一步引入轻微的不对称口角、轻薄上唇与口下投影 | 同上 + 上下唇、嘴角、颏唇沟 |

所有三幅真实渲染的头像均为 HTML + CSS；脚本只选择 CSS 规则和控制参数，不用图片、SVG、Canvas、AI 生图素材绘画。

## 可执行盲评协议

1. 从仓库运行 `npm run build`，访问 `study/005-blind.html`；直接打开本地文件也可尝试，浏览器限制时请使用本地 HTTP 服务。
2. 每位观察者在自己的会话中看到随机重排的匿名 A/B/C。三个 iframe 分别渲染源代码的三种方案，参数全部恢复成同一套默认值（脸宽 100%、光照 -30°）。
3. 观察者不知道方案具体名称，不使用浏览器开发工具，按眼窝自然度、嘴部自然度、整体可信度各给 1–5 分。可打相同分数。
4. 点击“导出匿名评分 JSON”；评分不会传到服务器。评审者主动把文件交给研究者后，研究者才能汇总。建议至少 **5 位互不讨论** 的独立观察者，最好包含绘画经验者。
5. 决定默认绘制方案之前，先公开评分数量、总分与离散程度。不能因为开发者个人偏好而宣布胜利。

## 当前发现与判断

原版较大的眼白和居中的圆形虹膜让人物显得机械；方案 `orbital` 减少了这个视觉现象，但可能让眼神更沉重。方案 `expression` 改变嘴角坡度和唇部体积，但差别很微弱。**哪个更像真人仍然未知。**

从实际截图看，最大的问题也许已经不是单独的眼睛与嘴，而是脸部形体的三维体面仍然不一致：颧骨、鼻根、额骨没有共享一致的体积解释。再往前应先验证实体结构表示的方法，而不是无限微调 CSS 数值。

## 下一轮的可检验问题

- 眼睛自然性是否可以通过眉弓/眶缘几何关系改善，而不是靠深灰遮罩？
- 面部光源改变时，鼻翼、上眼睑、颧骨的投影是否沿同一方向变化？
- CSS 路线产生艺术上的边际收益是否已接近成本拐点？如是，应提出一个**明确隔离的 SVG 绘制对照实验**，绝不把它宣称为纯 CSS 成果。
