## 修正方法，不放宽阈值
布尔几何全部采用一致的 1e-5 像素精度格网与 valid-output 处理，结合显式精度并集。此精度比原有0.1像素轮廓简化细10000倍；不跳过人物、不把形状取凸包、不改变像素/轮廓验收门槛。新增极近线段与孔洞合成回归。仍须六人物真实测试通过后才能完成。
参考：https://shapely.readthedocs.io/en/2.1.1/reference/shapely.set_precision.html

## 同批质量修正
衍生描述与独立HTML保留完整MIT许可。用户零系数中性样本是合法输入；非仿射残差下限只用于六份身份验证样本，不阻止用户生成中性头部。评审绑定查看模式，其他会话的未解决拒绝/修改不能被后来一次接受覆盖。机器/人工分开。自动化评审只写临时库并标记 AUTOMATED_TEST；展示截图在自动评分前拍摄，保留人工待评审状态。导出作品及评审做实际浏览器下载检查。

## 明确边界
当前版本由本地 Python API 计算数值几何，JavaScript 将区域交给 CSS 绘制；尚未移植为完全浏览器端 JavaScript 算法。编译器不读取参考图片，不逐像素画图。Python 服务依赖必须如实说明。
用户桌面连接离线，没有安装到用户电脑或公开部署。沙箱浏览器导航受管理员限制，不绕过，也不以合成画面冒充真实 API/UI。Docker 是待目标机器构建验证的部署模板，不是已上线服务。
