# S2 — 头部结构与形体概括

**READY / 尚未实施。艺术质量仍为 ART_UNVERIFIED。** 前置 S0、S1 已完成限定范围的参考校准与基本形体实验；不代表已经画出可信的人脸。

## 从哪里接续

先读 S1 报告与证据，不重跑一次“安装工具”当作新成果。沿用共享坐标、明确光照、几何导出的轮廓与预算意识；保留 A16、被拒绝 B16 与 C32 对照。不要直接把整个 S1 凸形体算法套在人脸：眼窝、鼻翼、口周有凹区与多重遮挡，必须单独建模。

## 第一项实际任务

确认可用开源头部几何及身份形变的具体版本/许可，建立至少三份可追溯身份参数，并预留另外三份不用于初始调优。S0 只验证了 ICT 中性头模型导入，不能误称已经导入整套身份/表情模型。输出颅面轮廓、眉弓/眼窝、鼻根/鼻部、颧骨、口周、下颌的共享结构表示与拓扑关系；图像和参考工具不得成为 CSS 贴图。

先给同一头部几何的离线参考与 CSS 简化结构图，再逐步添加有限明暗区域。不得用三个整脸缩放副本或三套人物专属 CSS 冒充独立身份。头部表面几何参考也不等于真实骨骼/肌肉解剖模型，需写明表示边界。

## 本阶段通过条件

三个不同身份使用同一算法生成结构图和无纹理体积图；几何/投影/光向相同的 B/C 可配对比较；新身份只改数据。保留原有默认人像基线，不接入毛孔、复杂发型、笔触和完整动画掩盖结构问题。

在正式实施前固定人头特有的测量与可证伪标准，不把 S1 的低 MAE 或32层预算直接当成人脸质量门槛。传统素描的整体到局部、边缘层次与造型自然度仍需后续实际作品检验。实验失败必须留下失败图与原因；自动化通过不等于真人写实通过。

结束时同一 PR 更新：S2报告、真实实验 evidence、尝试/失败记录、stages.json、STATUS.md，附当前提交完整 CI。未完成前不把此 READY 改为 COMPLETE。
