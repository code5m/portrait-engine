## 研究对象

固定 ICT FaceKit Light MIT 来源、提交与文件散列，读取六个身份形变模式。三份基准人物加三份内部预留参数，使用同一拓扑、同一中性头部相机和区域分配。它们是合成形状身份，不是被识别或命名的真人，也不宣称有性别、年龄或民族分类能力。

以真实变形头部表面生成受限数量的 CSS 明暗和结构区域。可见性通过投影三角形的重叠与平面深度裁剪计算，再按等明暗或结构区域合并。传给浏览器的是合并后的矢量轮廓，而不是逐像素深度图、截图转矢量、每三角片一个 DOM 或贴图。Blender 独立计算同几何、相机和法线光照。

八个结构区域只是额部、眼眶、鼻部、面颊、口周、下颌、眼球和头部的表面概括，不是直接推断医学骨骼或肌肉。区域在中性拓扑固定，随身份形变联动。本阶段限定正面、中性表情；皮肤、头发、光源投影遮挡和艺术边缘留给后续研究。

## 测量前固定协议

六人物×三光照=18场景，每场景有无纹理体积与结构区域两份 CSS 图，共36帧，加18份 Blender 参考。统一320px正交相机、24明暗区域，禁止人物专属 CSS。

正式模型测量之前固定：全图 MAE<7、内部 MAE<9、中央五官窗 MAE<14、轮廓 IoU≥0.975、明暗区域≤25、结构区域≤12、轮廓点≤60000、描述≤2MB。身份相对中性头部的非仿射残差 RMS≥0.0005（按头部取景跨度归一化）。这些是几何/表达保真阈值，不是艺术评分。
