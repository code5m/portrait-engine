## 接续的第一个实验

S0 暴露平色区域的阶梯灰带。先沿用同一组三形体×三光向，比较：

A. 16 个平色 CSS 区域（S0 基线）。
B. 16 个带内连续渐变的 CSS 区域（候选，尚无实现）。
C. 32 个平色区域（成本对照，不默认认定更多区域更好）。

只改变表示方式，保持几何、相机、光源、色彩和视口一致。不用全图 blur 掩盖轮廓失真。每形体最多 32 个绘制区域；记录 DOM、曲线样本、实际运行时间及全部九图。B 若不能在未参与调优的参数下保持结构，不能仅凭一张更柔和的截图保留。

必须同时报告内部误差、全图误差、轮廓附近误差及可见色带，不能只优化 S0 内区 MAE。先做测量和复现，再给候选设定明确可证伪标准；不得根据跑出的有利结果偷偷修改验收阈值。
