## 1. 问题、控制组与预先固定协议

S0 的 16 层平色存在可见阶梯。S1 不为一个人物继续补渐变，而研究：能否用同一套几何、法线与光照算法，在有限 CSS 区域预算下提高形体明暗保真，并推广到圆柱、楔形和投影。

[`s1-scenes.json`](../../research/sketch/s1-scenes.json) 固定了 27 场景：15 基准、12 内部预留参数场景。球属于椭球的一种，不能把三种椭球说成三个人物。15 个椭球场景比较 A16/B16/C32，其余形体扩展检验统一结构方法。预留参数在通用错误调试时可见，并非外部独立盲测。

- A16：逐字复用 S0 函数，16 层平色控制组。
- B16：16 层带内径向渐变假设。只有两组的内部、全图与一阶差分误差均 ≤ A 的 90%，边缘 ≤ A+1，才采用。
- C32：32 层平色成本对照。两组内部误差须 ≤ A 的 70%，全图不得变差。不能事后降低阈值。

原验收限值保持不变：选中表示内部 MAE<6、全图 MAE<6、边缘 MAE<35；Blender/解析内部 MAE<4，CSS/Blender 内部 MAE<6；投影 IoU≥0.96、质心偏差<2px。单位为 0–255 灰阶；内区为轮廓内缩 4px，边区是内缩和外扩 4px 间区域。每形体最多 32 明暗层，容器/平面单独计数。

## 3. 实现真正完成了什么

球/椭球使用逆 Gauss 映射与等照度轮廓，反光时按直接光明/暗两分支保留球面交集的弯月和不连通轮廓。圆柱采用旋转解析侧面与独立端盖，嵌套超水平角度区域避免相邻条带的白色抗锯齿缝。楔形由平面法线统一受光并选择可见面。不是按场景 id 手工绘图。

投影由同一个形体 support 函数确定接触平面，沿光线方向推导边界。独立 Python 射线求交和 Cycles 太阳光/接收平面验证它，不是手画扁椭圆。

反光附加项为 `bounceStrength * receiverAlbedo * direct * max(G·L,0) * (1-N·G)/2`。独立半球积分检验该公式；反射率置零完全消除附加项。这是无限均匀受光漫反射地面的**半球近似**，不是完整 GI。Blender 表面明暗也评估相同近似，只独立计算表面法线；不能用它证明该近似等于现实多次反光。

资料：[PBRT 漫反射](https://www.pbr-book.org/4ed/Reflection_Models/Diffuse_Reflection)、[Blender Cycles 射线可见性](https://docs.blender.org/manual/en/4.0/render/cycles/object_settings/object_data.html)。未复制第三方 GPL 代码到运行时，参考图片不作为 CSS 输入。
