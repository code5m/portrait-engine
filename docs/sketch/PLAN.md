# 素描生成研究 S0–S6

> 研究的是通用生成能力，人物作品是验证手段，写实质量是核心衡量标准。

阶段编号是成果标准，不是新增模块计数。当前完成状态只读 `research/sketch/stages.json`。

| 阶段 | 核心实验 | 交付与判据 |
|---|---|---|
| S0 | 原理资料、开源参考工具、坐标/颜色/光照校准、旧画像基线 | 可运行的参考/CSS 同数据对照；锁定第三方来源；不能只安装软件 |
| S1 | 基本形体与明暗、投影、反光、灰阶分组 | 同算法跨球/椭球/圆柱/楔形；分清形体阴影与投影，不按每张图手调 |
| S2 | 颅面、眼窝、鼻根、颧骨、口周、下颌结构 | 三身份的结构图和无纹理体积图；另外留出未参与调优的身份参数 |
| S3 | 多人物大明暗、半调子、遮挡与环境反射 | 无纹理仍有可信体积；灰斑问题未解决就回查模型，不堆细节 |
| S4 | 硬/软/失边、眼睑与眼球、鼻翼与面颊等连接 | 同几何同光照对照边缘策略；不通过全图模糊掩盖错误 |
| S5 | 顺形体排线、发束与材料组织 | 纯块面/规则排线/形体笔触比较；细节不能破坏结构或无界增加 DOM |
| S6 | 陌生人物、表情、光照、性能、独立评价 | 全样本与失败记录；新身份不加专属 CSS；盲评支持而非机器自称写实 |

三路证据：A 为现有 CSS 人像基线；B 为开源模型/离线参考；C 为同几何、相机与光照数据的 CSS 实现。只有 B/C 的输入一致时才比较保真误差。S0 的 ICT 导入样例与 A 的人物不同，不能进行伪配对的人像优劣比较。

S0 的基本形体只校准研究工具，是 S1 的最小起点，不代表解决了投影、反光、头部解剖、皮肤与发丝。离线参考图绝不能嵌入 CSS 冒充原生生成。

每阶段交付：问题 → 假设与反证标准 → 通用方法 → 真实对照图 → 数据/来源版本 → 局限与失败 → 继续/修订决定。完成同一 PR 必须更新报告、证据、台账和 STATUS.md。
