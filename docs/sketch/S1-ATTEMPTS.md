## 局部调试 / 不算阶段完成

- B16 椭圆径向渐变假设：局部 inline 浏览器对照显示内部误差较 A16 更大，保留候选等待相同 CI 条件确认；不能仅凭更柔和就采用。
- 初始圆柱相邻角条带有明显白色抗锯齿缝隙，端盖边缘若用直线弦也会错。修复为嵌套超水平角度区域并采样解析端盖曲线；同方法用于两组圆柱，不加 id 特判、不全图模糊。
- 页面排版令截取框落在小数像素位置，截图可能变成 257×256。捕获时只改页面外围排版，将 256×256 视口放到整数原点；不缩放、不后期重采样图像。
- 球面区域占用测试首次将有限轮廓多边形的亚像素弦高误差当作内部拓扑错误。改为按曲线采样数和椭球轴比计算边缘弦高界；内区拓扑必须精确，真实图像的全图/边缘 MAE 门槛未改。
- 增加合成图全图误差和场景/模式唯一覆盖校验，不能只保存截图数量就判通过。

环境无法本地运行 Blender，sandbox 使用 inline-debug 只能验证算法、控件与 CSS 帧；不伪造 file:// 或 CI provenance。完成状态必须以实际 GitHub Blender + Chromium 运行为准。
