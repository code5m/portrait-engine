# S0 — 素描原理与研究基线

**阶段状态：COMPLETE / CALIBRATION_COMPLETE。艺术质量：ART_UNVERIFIED。**

本阶段完成的是研究工具、参考输入和几何/光照到 CSS 的最小校准，并非完成传统素描全部原理，更不是已经画出可信真人。实验报告与 [原始证据快照](../../research/sketch/evidence/S0.json) 一起提交。

## 1. 研究问题与方法

检验同一几何、相机、光向能否转为可对照的 CSS 明暗，而不是为每张脸单独堆渐变。三个基本物体是球、宽椭球、长椭球，**不是三个人物身份**。

- 结构：逆 Gauss 映射 `p_i = r_i² n_i / sqrt(sum(r_j² n_j²))`。这是椭球的数学性质，不自动推广到人脸多重遮挡。
- 明暗：`ambient + direct * max(0, N·L)` 为受控方向诊断；常数 ambient 不是物理反光。明暗交界没有强制描黑，不混称漫反射最亮部与镜面高光。
- CSS：将等照度轮廓 `N·L=t` 投影为 16 个 CSS clip-path 区域，不逐像素生成 DOM，不逐三角片复制整张网格。
- 整体到局部：同数据输出三灰阶和 16 级灰阶，对比信息简化；这不是完整素描材料或艺术效果验证。
- 参考：Blender 执行同一法线诊断；ICT 中性人头仅做导入与 Freestyle 运行验证，**没有导入 CSS 人像引擎**，与现有 CSS 画像不是同一个身份，不能做伪配对优劣比较。

## 2. 预定验收边界（没有在看到结果后降低）

九组同场景：参考与解析误差 MAE < 4、CSS 与解析/参考 MAE < 6（0–255 灰阶；投影椭圆内部 q<0.92，排除栅格边缘）。这是坐标、颜色、法线的校准容差，**不是写实分数**。全图和边缘保留供观察，不能用内区指标宣称边缘问题解决。

上游提交和文件散列必须匹配；Blender 真实输出九基本形体及两个人头参考帧；Chromium 真实 file:// 导航输出九个 16 区域形体及三个三灰阶形体，且无外部图片请求；复现原 CSS 画像九帧；结果带实现源码摘要。受限环境的 `S0_INLINE=1` 仅用于调试，不允许成为 CI 完成证据。

## 4. 从实验能够与不能推出的结论

**能够推出：**对这三种椭球和固定正交视角，统一的法线/光照算法可以生成少量 CSS 区域；其内部灰度响应与独立 Blender 参考接近。开源参考 → 同输入 CSS 校准的通路已跑通，有明确出处、版本、误差和失败记录。

**不能推出：**三种椭球不等于通用人脸；没有证明投影、真实间接光、骨骼解剖、眼窝遮挡、皮肤、发丝或自然表情。ICT 只是参考工具导入验证，尚未将人脸几何转为 CSS。没有独立真人评价，不能声称人物写实质量已提升。

**暴露的问题：**16 层平色区仍有可见灰带，边界由有限采样曲线近似。下一阶段要比较连续渐变表达与增加区域数的成本，而不是直接堆人像细节。
