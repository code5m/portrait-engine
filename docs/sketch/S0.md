# S0 — 素描原理与研究基线

**状态：IN_PROGRESS。艺术质量：ART_UNVERIFIED。** 本文是预先记录的实验方法与验收边界；待真实运行后追加结果，不能由脚本存在推断通过。

## 研究问题与方法

检验同一几何、相机、光向能否转为可对照的 CSS 明暗，而不是为每张脸单独堆渐变。三个基本物体是球、宽椭球、长椭球，**不是三个人物身份**。

1. 结构：逆 Gauss 映射 `p_i = r_i² n_i / sqrt(sum(r_j² n_j²))`。这是椭球的数学性质，不自动推广到人脸多重遮挡。
2. 明暗：`ambient + direct * max(0, N·L)` 为受控方向诊断；常数 ambient 不是物理反光。明暗交界没有强制描黑，不混称漫反射最亮部与镜面高光。
3. CSS：将等照度轮廓 `N·L=t` 投影为 16 个 CSS clip-path 区域，不逐像素生成 DOM，不逐三角片复制整张网格。
4. 整体到局部：同数据输出三灰阶和 16 级灰阶，对比信息简化；这不是完整素描材料或艺术效果验证。
5. 参考：Blender 执行同一法线诊断；ICT 中性人头仅做导入与 Freestyle 运行验证，**没有导入 CSS 人像引擎**。

## 预定验收

九组同场景：参考与解析误差 MAE < 4、CSS 与解析/参考 MAE < 6（8-bit 灰阶；投影椭圆内部 q<0.92，排除栅格边缘）。这只是坐标、颜色、法线的校准容差，不能称为写实分数。全图与边缘仍保留供观察。

上游提交和文件散列必须匹配；Blender 真实输出九基本形体及两个人头参考帧；Chromium 真实文件导航输出九个 16 区域形体及三个三灰阶形体，且无外部图片请求；复现原 CSS 画像九帧；结果带实现源码摘要。参考失败则 S0 不完成，不能拿 JS 自测代替参考实验。

- [Proko Light and Form](https://www.proko.com/course-lesson/shading-light-and-form-basics)：形体阴影与投影的区分。只转述，不复制课程图片。

- [PBRT Diffuse Reflection](https://www.pbr-book.org/4ed/Reflection_Models/Diffuse_Reflection)：漫反射与入射余弦项。这里只是方向诊断，没有完整光传输。
- [Blender Freestyle](https://docs.blender.org/manual/en/4.5/render/freestyle/introduction.html)：线条参考，不是完整铅笔素描系统；外部进程运行，不复制 GPL 实现进 MIT 渲染器。
- [ICT-FaceKit 固定版本](https://github.com/USC-ICT/ICT-FaceKit/tree/da5f95a607f5e6b37755b38d3385d7f2853732e5)：仅锁定中性网格和 MIT LICENSE，下载至忽略的测试输出，校验 Git blob SHA。
