## 方法与不变的判据

同一几何、相机、光向分别进入 Blender 与 CSS。球、宽椭球、长椭球是三种基本形体，不是三个人物。逆 Gauss 映射为 `p_i=r_i²*n_i/sqrt(sum(r_j²*n_j²))`；受控明暗为 `ambient+direct*max(0,N·L)`，其中常数 ambient 不是物理反光。等照度曲线转成 16 个 CSS clip-path 区域，不逐像素创建 DOM、不复制网格三角形、不嵌入参考图片。

九组同场景：Blender/解析 MAE < 4，CSS/解析及 CSS/Blender MAE < 6。单位为 0–255 灰阶，评价区域为投影椭圆内部 q<0.92；不能据此声称轮廓或艺术质量达标。三灰阶用于研究整体归纳。

来源散列必须匹配；真实 file:// Chromium 导航，无外部资源/浏览器错误。`S0_INLINE=1` 仅可调试，不能成为完成证据。Blender 必须用 `--python-exit-code 1`，错误不能以退出码 0 混过。
